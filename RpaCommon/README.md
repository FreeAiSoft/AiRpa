# RpaCommon

Общие модели и вспомогательные типы для RPA (`.NET Framework 4.7.2`).

## Что внутри

- Результаты вызовов и ошибки: `CallResult<T>`, `Error`.
- Модели прокси и IP-информации: `Proxy`, `IpInfo`, `TZ`.
- Перечисления (`LogLevel`, `ProxyProtocol`, `IpApiClientStatus` и др.) и уведомление об изменении свойств (`NotifyPropertyChanged`).

## Зависимости

- Newtonsoft.Json `13.0.3`
