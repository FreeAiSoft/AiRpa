# Управление проектом

## Обзор

Управление проектом в студии осуществляется через `ProjectManager`. Проект
объединяет workflow-файлы, активности и настройки сборки.

## Возможности

- Создание нового проекта (мастер создания).
- Открытие существующего проекта/решения (`.sln`, `.csproj`).
- Управление файлами проекта: добавление, переименование, удаление.
- Сборка проекта через MSBuild.
- Просмотр ошибок и предупреждений компиляции.

## Структура

Проект студии — обычный .NET Framework 4.8 проект (WPF/библиотека), содержащий
workflow-файлы (`.xaml`) и классы активностей.

## См. также
