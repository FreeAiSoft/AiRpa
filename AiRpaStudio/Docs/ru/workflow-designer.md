# Дизайнер рабочих процессов

## Обзор

Дизайнер рабочих процессов (workflow designer) — основная рабочая область студии.
Он построен на `System.Activities.Presentation.WorkflowDesigner` (Windows Workflow
Foundation) и позволяет визуально собирать RPA-процессы из активностей.

## Основные возможности

- Создание, открытие и сохранение workflow-файлов (`.xaml`).
- Перетаскивание активностей из панели инструментов на поверхность дизайнера.
- Редактирование свойств выбранной активности в панели свойств.
- Отслеживание изменений: кнопки «Сохранить» и «Сохранить всё» включаются только
  после изменения workflow (см. `WorkflowEditTracking`).
- Интеллектуальный редактор выражений (Roslyn) с подсказками IntelliSense.

## Жизненный цикл

1. Создайте или откройте проект.
2. Создайте новый workflow или откройте существующий.
3. Добавьте активности из доступных библиотек.
4. Сохраните изменения.

## Несохранённые буферы закрытых документов

При закрытии изменённой вкладки (редактор кода/XAML или дизайнер workflow) её
несохранённый буфер не теряется, а кладётся в коллекцию несохранённых буферов.

- **Закрытие вкладки** — буфер изменённого документа сохраняется в коллекции
  (для дизайнера — сериализованный XAML, для редактора — текст и признак «изменён»).
- **«Сохранить всё»** — записывает в файлы и открытые изменённые документы, и
  буферы из коллекции; после записи запись из коллекции удаляется.
- **Повторное открытие файла** — буфер и состояние подгружаются из коллекции
  во вкладку, запись из коллекции удаляется (дальше буфером владеет открытая вкладка);
  последующее «Сохранить» пишет его в файл.
- **Удаление файла** из дерева проекта не сохраняет буфер (буфер отбрасывается,
  чтобы не «воскрешать» удалённый файл).
- **Закрытие студии / смена проекта** — показывается диалог «Сохранить / Не сохранять /
  Отмена»; «Не сохранять» очищает коллекцию несохранённых буферов.
