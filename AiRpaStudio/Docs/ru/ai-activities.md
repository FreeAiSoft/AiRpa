# Добавление активностей через AI

## Введение

AI Agent в AiRpaStudio позволяет добавлять активности в рабочий процесс с помощью
обычных текстовых команд на естественном языке. Вместо того, чтобы вручную
перетаскивать активности из панели инструментов, вы можете просто описать, что нужно
сделать, и AI создаст необходимые активности автоматически.

## Быстрый старт

### Шаг 1: Откройте или создайте Workflow

Перед использованием AI убедитесь, что у вас открыт workflow:
- Создайте новую активность: `Файл → New activity (C# ExpressionEditor)`
- Или откройте существующую: `Файл → Open`

### Шаг 2: Откройте панель AI Agent

AI Agent Chat должен быть виден на правой панели вместе с Properties и Log.

### Шаг 3: Напишите команду

Просто опишите, что вы хотите добавить:
```
Добавь активность Sequence
```

### Шаг 4: Дождитесь подтверждения

AI создаст активность и вы увидите:
- ✅ Сообщение об успешном добавлении
- Активность появится в вашем workflow

## Примеры команд

### Базовые активности

#### Добавить Sequence
```
Добавь Sequence с именем "Главный процесс"
```

#### Добавить WriteLine
```
Добавь WriteLine с текстом "Hello, World!"
```

#### Добавить Delay
```
Добавь задержку на 2 секунды
```

### Контейнерные активности

#### Sequence с несколькими действиями
```
Создай Sequence с тремя WriteLine:
1. "Начало процесса"
2. "Выполнение..."
3. "Конец процесса"
```

#### If условие
```
Добавь условие If:
- Если переменная counter больше 10
- Then: вывести "Много"
- Else: вывести "Мало"
```

#### While цикл
```
Создай цикл While, который выполняется пока counter < 10:
- Увеличить counter на 1
- Вывести текущее значение
```

### Сложные сценарии

#### TryCatch обработка ошибок
```
Добавь блок обработки ошибок:
- Try: выполнить операцию
- Catch: вывести сообщение об ошибке
```

#### ForEach цикл
```
Создай цикл ForEach для обработки списка items:
- Вывести каждый элемент
- Добавить задержку 1 секунду между элементами
```

## Доступные типы активностей

### Control Flow (Управление потоком)
- **Sequence** - последовательное выполнение активностей
- **If** - условное ветвление
- **While** - цикл с предусловием
- **DoWhile** - цикл с постусловием
- **ForEach** - цикл по коллекции
- **Switch** - множественное ветвление

### Flowchart (Блок-схема)
- **Flowchart** - визуальная блок-схема
- **FlowDecision** - узел решения
- **FlowSwitch** - множественное ветвление

### State Machine (Конечный автомат)
- **StateMachine** - конечный автомат
- **State** - состояние
- **FinalState** - конечное состояние

### Primitives (Примитивы)
- **Assign** - присвоение значения переменной
- **Delay** - задержка выполнения
- **InvokeMethod** - вызов метода
- **WriteLine** - вывод текста в консоль

### Collection (Коллекции)
- **AddToCollection** - добавить элемент в коллекцию
- **ClearCollection** - очистить коллекцию
- **ExistsInCollection** - проверить наличие элемента
- **RemoveFromCollection** - удалить элемент из коллекции

### Error Handling (Обработка ошибок)
- **TryCatch** - обработка исключений
- **Throw** - генерация исключения
- **Rethrow** - повторная генерация исключения

### Browser (Браузер)
- Активности для работы с веб-браузером

### Flow (Поток)
- Дополнительные активности для управления потоком

## Советы и рекомендации

### 1. Будьте конкретны

❌ Плохо:
```

```

✅ Хорошо:
```

```

### 2. Указывайте параметры

❌ Плохо:
```
Добавь задержку
```

✅ Хорошо:
```
Добавь задержку на 3 секунды
```

### 3. Используйте понятные имена

✅ Хорошо:
```
Создай Sequence с именем "Инициализация переменных"
```

### 4. Описывайте структуру для вложенных активностей

✅ Хорошо:
```
Создай Sequence "Обработка данных" с такими шагами:
1. Прочитать файл
2. Обработать данные
3. Сохранить результат
```

## Часто задаваемые вопросы

### Вопрос: Как добавить активность в конкретное место workflow?

**Ответ:** В текущей версии активности добавляются в конец корневого контейнера
(Sequence или Flowchart). Для добавления в конкретное место используйте стандартный
drag-and-drop.

### Вопрос: Можно ли редактировать добавленные активности через AI?

**Ответ:** В текущей версии - нет. Используйте Properties панель для изменения
параметров. Функция редактирования через AI планируется в будущих версиях.

### Вопрос: Что делать, если AI не понимает команду?

**Ответ:** Попробуйте:
1. Переформулировать запрос более конкретно
2. Использовать точные названия активностей (Sequence, If, While)
3. Разбить сложную команду на несколько простых

### Вопрос: Как узнать, какие активности доступны?

**Ответ:** Спросите AI:
```
Какие активности доступны?
```
или
```
Покажи список всех активностей для работы с браузером
```

### Вопрос: AI добавил не ту активность. Как отменить?

**Ответ:** Используйте кнопку Undo (Ctrl+Z) на панели инструментов или удалите
активность вручную из workflow.

## Примеры реальных сценариев

### Сценарий 1: Чтение и обработка CSV файла

**Команда:**
```
Создай процесс для чтения CSV файла:
1. Sequence "Обработка CSV"
2. Assign для пути к файлу
3. Прочитать все строки
4. ForEach для обработки каждой строки
5. WriteLine для вывода результата
```

### Сценарий 2: Веб-автоматизация

**Команда:**
```
Создай процесс веб-автоматизации:
1. Открыть браузер
2. Перейти на сайт
3. Заполнить форму
4. Нажать кнопку submit
5. Подождать результата
6. Закрыть браузер
```

### Сценарий 3: Обработка с ошибками

**Команда:**
```
Создай надежный процесс с обработкой ошибок:
1. TryCatch блок
2. В Try: выполнить основную логику
3. В Catch: залогировать ошибку и отправить уведомление
4. В Finally: очистить ресурсы
```

## Ограничения

### Текущая версия не поддерживает:
- Редактирование существующих активностей
- Удаление активностей
- Добавление в конкретную позицию workflow
- Генерацию сложных выражений (C#/VB expressions)
- Работу с custom активностями (пока)

### Эти функции запланированы в будущих версиях!
