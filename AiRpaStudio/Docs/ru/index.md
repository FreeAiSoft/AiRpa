# 📘 Справка AiRpaStudio

**AiRpaStudio** — WPF-студия для визуальной разработки RPA-роботов на базе
Windows Workflow Foundation. Позволяет собирать процессы из активностей,
управлять проектами и NuGet-зависимостями, запускать и отлаживать роботов.

| 🧩 Фича | 📝 Описание | 📄 Документация |
|---------|-------------|-----------------|
| 🧩 Дизайнер рабочих процессов | Визуальная сборка `.xaml`, редактор выражений C#/VB | [workflow-designer.md](workflow-designer.md) |
| 🧰 Активности | Каталог активностей и создание собственных библиотек | [activities.md](activities.md) |
| 📁 Управление проектом | Создание, открытие и сборка проекта | [project-management.md](project-management.md) |

| ⚙️ Настройки | Язык, тема, AI-провайдер, прокси | [settings.md](settings.md) |
| 🔌 MCP-сервер | Инструменты студии для внешних клиентов | [mcp-server.md](mcp-server.md) |

## ⚡ Быстрый старт

1. 📂 Создайте или откройте проект (`Файл → Новый проект`).
2. 🧩 Откройте или создайте workflow.
3. 🧰 Перетащите активности на дизайнер — или опишите их текстом в AI-чате.
4. 💾 Сохраните workflow и соберите проект.
5. ▶️ Запустите робота и проследите выполнение.
