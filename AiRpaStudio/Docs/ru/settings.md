# Настройки

## Обзор

Настройки студии хранятся через `Properties.Settings` и сохраняются методом
`Save()`. Локализация (RU/EN) выбирается через `Properties.Settings.Language`.

## Основные настройки

- Язык интерфейса (RU/EN).
- Настройки AI-провайдера для чата (ключ API, модель, base URL).
- Разрешения агента (AgentPermissions): чтение файлов, редактирование,
  выполнение команд, доступ в интернет, субагенты.
- Настройки прокси (WebProxy).
- Параметры распознавания речи (STT).

## Хранение

- Настройки приложения — `Properties.Settings`.
- Настройки чата — JSON в `%AppData%\AiRpaStudio\Chat\chat_settings.json`.
