# Дизайнер рабочих процессов

## Обзор

Дизайнер рабочих процессов (workflow designer) — основная рабочая область студии.
Он построен на `System.Activities.Presentation.WorkflowDesigner` (Windows Workflow
Foundation) и позволяет визуально собирать RPA-процессы из активностей.

## Основные возможности

- Создание, открытие и сохранение workflow-файлов (`.xaml`).
- Перетаскивание активностей из панели инструментов на поверхность дизайнера.
- Редактирование свойств выбранной активности в панели свойств.
- Отслеживание изменений: кнопки «Сохранить» и «Сохранить всё» включаются только
  после изменения workflow (см. `WorkflowEditTracking`).
- Интеллектуальный редактор выражений (Roslyn) с подсказками IntelliSense.

## Жизненный цикл

1. Создайте или откройте проект.
2. Создайте новый workflow или откройте существующий.
3. Добавьте активности из доступных библиотек.
4. Сохраните изменения.
