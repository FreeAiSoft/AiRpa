# Активности

## Обзор

Активность (activity) — базовый строительный блок workflow. Каждая активность
описывает одно действие: работа с браузером, файлами, операционной системой,
управлением потоком выполнения и т.д.

## Категории

- `Activities` — базовые и общие активности.
- `Activities.Browser` — работа с браузером (запуск, переход по URL, клики, ввод текста, JS).
- `Activities.Files` — работа с файлами и папками.
- `Activities.OS` — взаимодействие с операционной системой.
- `Activities.Flow` — управление потоком выполнения (условия, циклы).
- `Activities.Debug` — отладочные активности.
- `Rpa.Activities.Primitives` — примитивные активности.

## Создание собственных активностей

Активности создаются по шаблону `ActivityLibrary` (см. `VSTemplates`). Каждая
активность — это класс, наследующий базовый класс активности, с дизайнером
(XAML) для визуального редактирования.
