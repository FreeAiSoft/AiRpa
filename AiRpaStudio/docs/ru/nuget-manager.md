# Менеджер NuGet пакетов

## Обзор

Менеджер NuGet пакетов (`RPA.NuGet`) позволяет искать, просматривать,
устанавливать, обновлять и удалять NuGet-пакеты для текущего проекта.
Дизайн и набор возможностей повторяют менеджер пакетов Visual Studio 2026, но
панель студии **без скруглений**: углы прямые, зоны разделяет линия 1px.

## Расположение

Менеджер открывается **вкладкой в панели документов** (пункт меню «NuGet» или
контекстное меню проекта → «Добавить зависимость»). Вкладку можно перетащить в
боковой док — тогда панель переключается в узкий режим: детали пакета
показываются вместо списка, кнопка «назад» возвращает к списку.

## Возможности

- Три вкладки: **Browse** (поиск в источнике), **Installed** (пакеты проекта),
  **Updates** (доступные обновления).
- Поиск с `Ctrl+L`, очистка по `Esc`, догрузка результатов кнопкой «Load more»,
  отмена долгого запроса кнопкой «Cancel».
- Переключатель **Include prerelease** влияет и на поиск, и на проверку обновлений.
- Выбор источника пакетов (`Package source`) из `NuGet.Config` (solution, user,
  global); шестерня открывает файл конфигурации. Если сопоставление источников не
  настроено, панель показывает плашку «Package source mapping is off.» со ссылкой.
- Строка пакета: иконка, звёздочка популярного пакета, идентификатор, авторы,
  описание, количество скачиваний и версия.
- Панель деталей: выбор версии (последняя стабильная, любая из списка),
  большая кнопка **Install / Update / Downgrade / Uninstall**, блок **Options**
  (prerelease, автоматический `msbuild -t:restore` после установки), вкладки
  **README** и **Package Details** (описание, авторы, лицензия, дата публикации,
  количество скачиваний, Project URL, Report Abuse, теги).
- README пакета читается из `.nupkg`, скачанного **из выбранного источника**
  (приватный и корпоративный источник тоже работают), и кешируется в памяти;
  если README получить не удалось, причина видна в строке состояния панели.
- Шеврон блока **Options** — кнопка без фона с иконкой Material: наведение мыши
  её не подсвечивает, раскрытие видно только по самой иконке.
- Пакетное обновление всех пакетов проекта на вкладке Updates.
- Установка обновляет `packages.config` или `<PackageReference>` в `.csproj`;
  для `packages.config`-проектов пакет ещё и распаковывается в `packages\`.
