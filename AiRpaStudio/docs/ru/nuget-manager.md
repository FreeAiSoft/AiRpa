# Менеджер NuGet пакетов

## Обзор

Менеджер NuGet пакетов (`RPA.NuGet`) позволяет искать, просматривать,
устанавливать, обновлять и удалять NuGet-пакеты для текущего проекта.

## Возможности

- Поиск пакетов в nuget.org через `NuGet.Protocol`.
- Просмотр версий и метаданных пакета.
- Установка пакета с обновлением `packages.config` / `.csproj`.
- Обновление и удаление установленных пакетов.

## Расположение

Менеджер доступен как пункт меню/тулбара и как докируемая панель главного окна.
