# MCP-сервер

## Обзор

Студия содержит MCP-сервер (`RPA.Mcp`), который предоставляет инструменты
(tools) для внешних клиентов по протоколу Model Context Protocol.

## Режимы работы

- `stdio` — через стандартный ввод/вывод.
- `http` — через HTTP-эндпоинт.

## Запуск

MCP-сервер запускается через параметр командной строки `--mcp-server` в
`App.xaml.cs`. Интеграция описана в `Models\McpIntegration.cs`.

## Важно

Новый встроенный чат студии с MCP-сервером не связан: MCP-сервер используется
как самостоятельная интеграция, а чат работает с собственным набором
инструментов агента.
