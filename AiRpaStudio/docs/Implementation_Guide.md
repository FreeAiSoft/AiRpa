## Детальные инструкции по реализации

### Как добавить новый тип активности

1. Зарегистрировать в `ActivityFactory._activityTypes`
2. Добавить описание в `ActivityPrompts.GetSystemPrompt()`
3. Добавить тест в `ActivityFactory.Tests`

### Как обработать специальный случай добавления активности

Если активность требует особой логики при добавлении:

```csharp
// В RpaAiIntegrationService.AddActivityToWorkflow()
if (activity is SpecialActivity special)
{
    // Специальная логика
}
```

### Формат JSON команд для AI

Простая активность:
```json
{
  "action": "add_activity",
  "activity": {
    "type": "WriteLine",
    "displayName": "Вывод сообщения",
    "parameters": {
      "text": "Hello, World!"
    }
  }
}
```

Контейнерная активность с детьми:
```json
{
  "action": "add_activity",
  "activity": {
    "type": "Sequence",
    "displayName": "Главный процесс",
    "children": [
      {
        "type": "WriteLine",
        "parameters": {
          "text": "Шаг 1"
        }
      },
      {
        "type": "Delay",
        "parameters": {
          "duration": "00:00:02"
        }
      }
    ]
  }
}
```

## Конфигурация Ollama

### Рекомендуемые модели

1. **llama2** - базовая модель, хорошо понимает структурированный JSON
2. **codellama** - специализируется на коде, отлично для технических команд
3. **mistral** - быстрая и точная
4. **llama3** (если доступна) - улучшенная версия

### Пример system prompt

```
Ты - ассистент RPA, который помогает создавать workflow. 
Когда пользователь просит добавить активность, отвечай JSON командой, 
а затем текстовым объяснением.

Доступные активности:
- Sequence: контейнер для последовательного выполнения активностей
- If: условное ветвление
- While: цикл с предусловием
- WriteLine: вывод текста в консоль
...

Формат ответа:
```json
{
  "action": "add_activity",
  "activity": {...}
}
```
Затем текстовое объяснение.
```

## Troubleshooting

### Проблема: AI не генерирует JSON команды

**Решение:**
1. Проверить system prompt в запросе
2. Использовать температуру 0.3-0.5 для более детерминированных ответов
3. Добавить примеры в system prompt

### Проблема: Не удается добавить активность в Designer

**Решение:**
1. Проверить, что Designer активен: `CustomWfDesigner.GetInstance().ActiveWorkflowDesignerEx != null`
2. Проверить тип root активности: должна быть Sequence или Flowchart
3. Проверить логи для деталей ошибки

### Проблема: Параметры не устанавливаются

**Решение:**
1. Проверить тип параметра в Activity
2. Использовать правильный тип значения (string, int, TimeSpan и т.д.)
3. Для Expression параметров использовать VB/C# Expression
