# Руководство по интеграции AI агента с MCP инструментами

## Обзор

AI агент в RPA Studio теперь автоматически получает доступ ко всем MCP (Model Context Protocol) инструментам при инициализации. Это позволяет AI понимать, какие команды доступны для управления workflow designer.

## Как это работает

### 1. Автоматическая загрузка инструментов

При запуске AI агента автоматически выполняются следующие действия:

```csharp
// В конструкторе AiAgentChatViewModel
_ = Task.Run(async () => await InitializeDefaultProviderAsync());
_ = Task.Run(async () => await LoadMcpToolsAsync());
```

### 2. Генерация системного промпта

Метод `LoadMcpToolsAsync()` автоматически:
- Загружает список всех доступных MCP инструментов через `_rpaIntegration.GenerateAiContextAsync()`
- Формирует детальное описание каждого инструмента с параметрами и примерами
- Устанавливает системный промпт, содержащий полную документацию по инструментам

### 3. Формат описания инструментов

Для каждого MCP инструмента AI получает:
- **Название инструмента**
- **Описание** - что делает инструмент
- **Параметры** - список всех параметров с указанием обязательности
- **Пример использования** - готовый JSON код для вызова

Пример для `add_activity`:
```markdown
### add_activity
**Описание:** Добавляет новую активность в workflow

**Параметры:**
- `activityType` *(обязательный)*: Тип активности (Sequence, If, While и т.д.)
- `displayName` *(опциональный)*: Отображаемое имя активности

**Пример использования:**
```json
{
  "action": "add_activity",
  "activityType": "Sequence",
  "displayName": "Моя последовательность"
}
```
```

## Доступные MCP инструменты

AI агент имеет доступ к следующим категориям инструментов:

### Инструменты для работы с Workflow

1. **add_activity** - Добавление новой активности
2. **list_activities** - Получение списка доступных типов активностей
3. **get_workflow_info** - Получение информации о текущем workflow
4. **remove_activity** - Удаление активности
5. **update_activity** - Обновление свойств активности
6. **save_workflow** - Сохранение workflow

### Инструменты для работы с файлами

1. **list_files** - Список файлов в директории
2. **read_file** - Чтение содержимого файла
3. **get_file_info** - Получение информации о файле
4. **search_files** - Поиск файлов по паттерну

## Как AI использует инструменты

### Процесс обработки команд

1. **Пользователь** отправляет запрос AI (например: "Создай Sequence с именем Test")
2. **AI** анализирует запрос и системный промпт с описанием инструментов
3. **AI** формирует JSON команду в своем ответе:
   ```json
   {
     "action": "add_activity",
     "activityType": "Sequence",
     "displayName": "Test"
   }
   ```
4. **ActivityCommandParser** извлекает команду из ответа AI
5. **RpaAiIntegrationService** выполняет команду через MCP сервер
6. **Результат** отображается пользователю в чате

### Пример взаимодействия

**Пользователь:** "Покажи мне, какие активности доступны"

**AI ответ:**
```
Сейчас получу список доступных активностей...

```json
{
  "action": "list_activities"
}
```

**Системное сообщение:**
```
✅ Successfully executed 1 command(s)
list_activities: Sequence, If, While, ForEach, Assign, WriteLine, ...
```

## Преимущества автоматической интеграции

1. **Нет необходимости в ручной настройке** - инструменты загружаются автоматически
2. **Актуальная информация** - AI всегда видит текущий список инструментов
3. **Детальная документация** - AI понимает параметры и использование
4. **Примеры кода** - AI может генерировать правильные JSON команды
5. **Многоязычность** - Описания на русском языке для лучшего понимания

## Расширение функциональности

### Добавление нового MCP инструмента

1. Создайте новый класс инструмента в `Mcp/Tools/`
2. Реализуйте интерфейс `IMcpTool`
3. Зарегистрируйте инструмент в `RpaMcpServer.cs`
4. Добавьте пример использования в `RpaAiIntegrationService.GenerateAiContextAsync()`

AI автоматически получит доступ к новому инструменту при следующей инициализации.

### Кастомизация системного промпта

Вы можете изменить системный промпт в методе `LoadMcpToolsAsync()` в файле `AiAgentChatViewModel.cs`:

```csharp
SystemPrompt = @"Ваш кастомный промпт...

" + mcpContext + @"

Дополнительные инструкции...";
```

## Устранение неполадок

### AI не видит инструменты

**Проблема:** AI не использует MCP инструменты в ответах

**Решение:**
1. Проверьте, что `LoadMcpToolsAsync()` вызывается в конструкторе
2. Убедитесь, что системный промпт содержит описание инструментов
3. Проверьте логи на наличие ошибок при загрузке инструментов

### Инструмент не работает

**Проблема:** AI генерирует команду, но она не выполняется

**Решение:**
1. Проверьте правильность JSON формата в ответе AI
2. Убедитесь, что инструмент зарегистрирован в `RpaMcpServer`
3. Проверьте параметры команды на соответствие схеме
