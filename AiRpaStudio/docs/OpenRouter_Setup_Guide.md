# Руководство по настройке OpenRouter

## Обзор

AiAgentChatControl теперь поддерживает два AI провайдера:
- **Ollama** (локальный) - бесплатный, работает без интернета
- **OpenRouter** (облачный) - доступ к 100+ моделям через API

## Настройка OpenRouter

### Шаг 1: Получение API ключа

1. Перейдите на https://openrouter.ai/
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел "Keys" (Ключи)
4. Создайте новый API ключ
5. Скопируйте ключ (он будет показан только один раз!)

### Шаг 2: Установка API ключа в приложении

Есть два способа установить API ключ:

#### Способ 1: Через файл настроек (рекомендуется)

1. Откройте файл настроек пользователя:
   - Windows: `%APPDATA%\RPA\user.config`
   - Или используйте меню приложения Settings

2. Найдите или добавьте параметр `OpenRouterApiKey`:
```xml
<setting name="OpenRouterApiKey" serializeAs="String">
    <value>your-api-key-here</value>
</setting>
```

3. Сохраните файл и перезапустите приложение

#### Способ 2: Программное добавление

```csharp
RPA.Properties.Settings.Default.OpenRouterApiKey = "your-api-key-here";
RPA.Properties.Settings.Default.Save();
```

### Шаг 3: Выбор провайдера

1. Откройте AI Agent Chat Control
2. В верхней панели найдите выпадающий список "Провайдер:"
3. Выберите "OpenRouter"
4. Дождитесь загрузки списка доступных моделей
5. Выберите нужную модель из списка "Модель:"

## Использование

### Выбор модели

OpenRouter предоставляет доступ к моделям от различных провайдеров:

**Рекомендуемые модели для начала:**
- `anthropic/claude-3.5-sonnet` - отличное качество, быстрая
- `openai/gpt-4-turbo` - очень качественная, универсальная
- `google/gemini-pro-1.5` - хорошее соотношение цена/качество
- `meta-llama/llama-3.1-70b-instruct` - бесплатная, хорошее качество

### Переключение между провайдерами

Вы можете свободно переключаться между Ollama и OpenRouter:

1. Выберите провайдера в выпадающем списке
2. Список моделей автоматически обновится
3. Выберите нужную модель
4. Начните общение

Выбранный провайдер сохраняется между сеансами.

### Стоимость использования

OpenRouter работает по принципу "pay-as-you-go":
- Оплата только за фактическое использование
- Разные модели имеют разную стоимость
- Проверяйте цены на https://openrouter.ai/models

**Совет**: Начните с бесплатных или недорогих моделей для тестирования.

## Устранение неполадок

### OpenRouter недоступен

**Проблема**: Сообщение "OpenRouter недоступен. Проверьте настройки API ключа."

**Решение**:
1. Проверьте правильность API ключа
2. Убедитесь, что есть интернет-соединение
3. Проверьте баланс на аккаунте OpenRouter
4. Попробуйте пересоздать API ключ

### Не загружаются модели

**Проблема**: Список моделей пустой или не загружается

**Решение**:
1. Нажмите кнопку "🔄 Обновить"
2. Проверьте статус OpenRouter на https://status.openrouter.ai/
3. Проверьте логи приложения на наличие ошибок

### Ошибки во время генерации

**Проблема**: Ошибка во время получения ответа

**Возможные причины**:
- Недостаточно средств на балансе
- Превышен лимит запросов (rate limit)
- Модель временно недоступна
- Слишком длинный контекст сообщения

**Решение**:
1. Проверьте баланс аккаунта
2. Подождите несколько минут и попробуйте снова
3. Попробуйте другую модель
4. Сократите длину сообщения или очистите историю чата

## Сравнение провайдеров

| Характеристика | Ollama | OpenRouter |
|----------------|--------|------------|
| **Расположение** | Локальный | Облачный |
| **API ключ** | Не требуется | Требуется |
| **Интернет** | Не требуется | Требуется |
| **Стоимость** | Бесплатно | По тарифу |
| **Модели** | Установленные локально | 100+ моделей |
| **Скорость** | Зависит от железа | Быстрая |
| **Приватность** | Полная (всё локально) | Зависит от политики провайдера |
| **Требования** | Мощный ПК с GPU | Только интернет |

## Рекомендации по использованию

### Когда использовать Ollama:
- Работа с конфиденциальными данными
- Нет интернет-соединения
- Есть мощный компьютер с GPU
- Не хотите платить за API

### Когда использовать OpenRouter:
- Нужны самые продвинутые модели (GPT-4, Claude 3.5)
- Нет мощного компьютера
- Нужна максимальная скорость ответа
- Хотите протестировать разные модели

## Безопасность

### Хранение API ключа

- API ключ хранится в зашифрованном виде в настройках пользователя
- Не передавайте свой API ключ другим лицам
- Регулярно ротируйте API ключи
- Используйте разные ключи для разных приложений

### Рекомендации:

1. **Не коммитьте API ключи в Git**
   - Добавьте `user.config` в `.gitignore`
   - Используйте переменные окружения для CI/CD

2. **Мониторинг использования**
   - Регулярно проверяйте использование на OpenRouter
   - Установите лимиты расходов
   - Получайте уведомления о необычной активности

3. **Ограничение прав**
   - Используйте API ключи с минимально необходимыми правами
   - Для тестирования создавайте отдельные ключи с лимитами
