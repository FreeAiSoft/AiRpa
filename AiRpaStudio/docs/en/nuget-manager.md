# NuGet Package Manager

## Overview

The NuGet package manager (`RPA.NuGet`) lets you search, browse, install, update
and remove NuGet packages for the current project.

## Features

- Search packages on nuget.org via `NuGet.Protocol`.
- Browse package versions and metadata.
- Install a package, updating `packages.config` / `.csproj`.
- Update and remove installed packages.

## Location

The manager is available as a menu/toolbar item and as a dockable panel in the
main window.
