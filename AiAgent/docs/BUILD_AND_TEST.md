# Инструкции по сборке и тестированию

## Сборка проекта

### 1. Открытие проекта

1. Откройте Visual Studio 2019 или выше
2. Откройте файл `AiAgent.sln`
3. Подождите, пока Visual Studio загрузит проект

### 2. Восстановление NuGet пакетов

**Автоматически:**
Visual Studio должен автоматически предложить восстановить пакеты.

**Вручную:**
```
Tools → NuGet Package Manager → Manage NuGet Packages for Solution
```
Нажмите кнопку "Restore" (Восстановить)

Или через Package Manager Console:
```powershell
Install-Package Newtonsoft.Json -Version 13.0.3
```

### 3. Сборка проекта

Выберите один из вариантов:
- **Меню**: Build → Build Solution (или F6)
- **Правая кнопка** на проекте → Build

Проект должен собраться без ошибок.

## Создание тестового приложения

Для тестирования контрола создайте простое WPF приложение:

### 1. Создайте новый WPF проект

1. File → New → Project
2. Выберите "WPF App (.NET Framework)"
3. Выберите .NET Framework 4.7.2
4. Назовите проект "AiAgentTestApp"

### 2. Добавьте ссылку на AiAgent

1. Правая кнопка на References → Add Reference
2. Projects → Solution → AiAgent
3. OK

### 3. Обновите MainWindow.xaml

```xml
<Window x:Class="AiAgentTestApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:control="clr-namespace:AiAgent.Control;assembly=AiAgent"
        Title="Тест чата с Ollama" 
        Height="700" 
        Width="900">
    <Grid>
        <control:AiAgentChatControl />
    </Grid>
</Window>
```

### 4. Запустите приложение

Нажмите F5 или кнопку "Start"

## Тестирование функциональности

### Предварительные требования

1. **Установите Ollama**
   - Скачайте с https://ollama.ai
   - Установите

2. **Загрузите модель**
   ```bash
   ollama pull llama2
   ```

3. **Убедитесь, что Ollama запущен**
   - Откройте http://localhost:11434 в браузере
   - Должна быть надпись "Ollama is running"

### Тестовые сценарии

#### Тест 1: Загрузка моделей
1. Запустите приложение
2. Проверьте, что в выпадающем списке "Модель" появились доступные модели
3. Если список пуст, нажмите кнопку "🔄 Обновить"

**Ожидаемый результат:** В списке появляются установленные модели (например, llama2:latest)

#### Тест 2: Отправка простого сообщения
1. Выберите модель из списка
2. Введите в поле ввода: "Привет! Как дела?"
3. Нажмите "📤 Отправить" или Ctrl+Enter

**Ожидаемый результат:** 
- Сообщение появляется в чате справа (синий фон)
- Начинается генерация ответа
- Ответ AI появляется слева (серый фон) и обновляется потоково

#### Тест 3: Потоковая передача
1. Отправьте сообщение: "Напиши длинный текст о космосе"
2. Наблюдайте за появлением текста

**Ожидаемый результат:** 
- Текст появляется постепенно, символ за символом
- Рядом с временем отображается "• Печатает..."
- После завершения индикатор исчезает

#### Тест 4: Отмена генерации
1. Отправьте сообщение: "Напиши очень длинный рассказ"
2. Во время генерации нажмите кнопку "⏹️ Остановить"

**Ожидаемый результат:** 
- Генерация останавливается
- Частично сгенерированное сообщение удаляется
- Статус: "Генерация отменена"

#### Тест 5: Очистка чата
1. Отправьте несколько сообщений
2. Нажмите кнопку "🗑️ Очистить"

**Ожидаемый результат:** 
- Все сообщения удаляются
- Чат пустой
- Статус: "Чат очищен"

#### Тест 6: Сохранение диалога
1. Отправьте несколько сообщений
2. Нажмите кнопку "💾 Сохранить"

**Ожидаемый результат:** 
- Статус: "Диалог сохранен"
- Файл создается в `%AppData%\AiAgent\Conversations\`
- Файл в формате JSON с GUID именем

#### Тест 7: Переключение моделей
1. Отправьте сообщение с одной моделью
2. Выберите другую модель из списка
3. Отправьте еще одно сообщение

**Ожидаемый результат:** 
- Ответы приходят от разных моделей
- История сохраняется

#### Тест 8: Работа без Ollama
1. Остановите Ollama
2. Попробуйте загрузить модели

**Ожидаемый результат:** 
- Появляется сообщение: "Ollama не запущен..."
- Предложение запустить Ollama

## Известные проблемы и решения

### Проблема: "Не удалось получить список моделей"
**Причина:** Ollama не запущен  
**Решение:** Запустите Ollama Desktop Application

### Проблема: Список моделей пуст
**Причина:** Нет загруженных моделей  
**Решение:** Выполните `ollama pull llama2`

### Проблема: Ошибка сериализации
**Причина:** Не установлен Newtonsoft.Json  
**Решение:** Восстановите NuGet пакеты

### Проблема: Медленная генерация
**Причина:** Зависит от производительности системы и размера модели  
**Решение:** Используйте меньшие модели или улучшите hardware

### Проблема: Текст не прокручивается автоматически
**Причина:** Баг в ScrollViewer  
**Решение:** Перезапустите приложение

## Производительность

### Рекомендуемые характеристики

**Минимальные:**
- CPU: 4 cores
- RAM: 8 GB
- Модель: llama2 (3.8 GB)

**Рекомендуемые:**
- CPU: 8+ cores
- RAM: 16+ GB
- GPU: NVIDIA с CUDA (опционально)
- Модель: любая

### Метрики производительности

- **Загрузка моделей:** < 1 секунды
- **Первый ответ:** 2-5 секунд (зависит от модели)
- **Streaming:** Плавное появление текста
- **Сохранение:** < 100 мс
