# AiAgentTest - Тестовое приложение

Это тестовое WPF приложение для проверки работы контрола `AiAgentChatControl`.

## Требования

1. **Ollama Desktop Application** - должен быть установлен и запущен
2. **Visual Studio 2019** или выше
3. **.NET Framework 4.7.2**

## Установка и запуск

### 1. Установите Ollama

```bash
# Скачайте с https://ollama.ai и установите
# Затем загрузите модель:
ollama pull llama2
```

### 2. Откройте решение в Visual Studio

1. Откройте файл `C:\Users\Maxxx\source\repos\MyBot\AiAgent.sln`
2. Visual Studio загрузит оба проекта:
   - **AiAgent** - библиотека с контролом
   - **AiAgentTest** - тестовое приложение

### 3. Восстановите NuGet пакеты

Visual Studio должен автоматически восстановить пакеты. Если нет:
- Правая кнопка на решении → Restore NuGet Packages

### 4. Установите AiAgentTest как стартовый проект

- Правая кнопка на проекте **AiAgentTest** → Set as Startup Project

### 5. Запустите приложение

- Нажмите **F5** или кнопку **Start**

## Что тестировать

### ✅ Проверка загрузки моделей
1. Приложение должно автоматически загрузить список моделей
2. В выпадающем списке должны появиться доступные модели
3. Если список пуст - нажмите кнопку "🔄 Обновить"

### ✅ Отправка сообщения
1. Выберите модель
2. Введите текст в поле ввода
3. Нажмите "Отправить" или **Ctrl+Enter**
4. Сообщение должно появиться справа (синий фон)
5. Ответ AI появится слева (серый фон) с потоковой передачей

### ✅ Потоковая передача
- Текст ответа должен появляться постепенно
- Рядом с временем показывается "• Печатает..."

### ✅ Остановка генерации
1. Во время генерации нажмите "⏹️ Остановить"
2. Генерация должна остановиться

### ✅ Очистка и сохранение
- Кнопка "🗑️ Очистить" - очищает чат
- Кнопка "💾 Сохранить" - сохраняет диалог в JSON

## Устранение проблем

### Ollama не запущен
**Симптом**: Сообщение "Ollama не запущен"  
**Решение**: Запустите Ollama Desktop Application

### Список моделей пуст
**Симптом**: В выпадающем списке нет моделей  
**Решение**: Выполните `ollama pull llama2`

### Ошибка сборки
**Симптом**: Проект не собирается  
**Решение**: 
1. Восстановите NuGet пакеты
2. Проверьте, что проект AiAgent успешно собран
3. Проверьте ссылку на проект AiAgent

## Расположение сохраненных диалогов

Диалоги сохраняются в:
```
C:\Users\Maxxx\AppData\Roaming\AiAgent\Conversations\
```

Каждый диалог - это отдельный JSON файл с GUID именем.
