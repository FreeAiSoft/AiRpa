# Activities.Browser

Библиотека активностей для автоматизации работы с веб-браузером на базе Windows Workflow Foundation (`.NET Framework 4.7.2`).

## Что внутри

- Управление браузером: запуск и закрытие, создание и переключение вкладок, навигация по URL, обновление страницы, переходы вперёд/назад, получение списка вкладок.
- Работа с элементами: поиск, ожидание, клик, ввод текста, чтение текста и атрибутов, выбор опции, скролл, проверка существования элемента.
- Выполнение JavaScript и скачивание файлов.

## Технологии

- PuppeteerSharp `20.2.2` для управления Chromium.
