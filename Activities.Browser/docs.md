## Введение

Activities.Browser — это набор активностей для автоматизации работы с веб-браузером. Библиотека предоставляет инструменты для управления браузером, навигации по страницам, взаимодействия с элементами и извлечения данных.

**Важно:** Все активности работают с CSS-селекторами и XPath-селекторами для поиска элементов на странице. Если указаны оба селектора, приоритет отдается CSS-селектору.

## Управление браузером

### StartBrowser

**Описание:** Запускает новый экземпляр браузера и открывает первую страницу.

**Входные параметры:**
- **ExecutablePath** (обязательный) — путь к исполняемому файлу браузера (например, chrome.exe)
- **Url** (необязательный) — начальный URL для открытия
- **UserDataDir** (необязательный) — путь к директории профиля пользователя для сохранения cookies, истории и настроек
- **Args** (необязательный) — дополнительные аргументы командной строки для браузера (разделенные пробелами)
- **Headless** (необязательный) — режим без графического интерфейса (true/false)

**Выходные параметры:**
- **Browser** — объект браузера для использования в других активностях
- **Page** — первая открытая страница браузера

**Советы:**
- Используйте `Headless = false` для визуального контроля процесса автоматизации
- `UserDataDir` позволяет сохранять сессию между запусками (полезно для работы с авторизацией)
- Аргументы могут включать `--window-size=1920,1080`, `--disable-notifications` и другие

### CloseBrowser

**Описание:** Закрывает браузер и освобождает все связанные ресурсы.

**Входные параметры:**
- **Browser** (обязательный) — объект браузера, полученный из StartBrowser

**Советы:**
- Всегда закрывайте браузер в конце сценария для освобождения ресурсов
- Используйте в блоке Try-Catch-Finally, помещая CloseBrowser в Finally для гарантированного закрытия

## Навигация

### GoToUrl

**Описание:** Переходит на указанный URL в текущей странице.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **Url** (обязательный) — URL адрес для перехода

**Советы:**
- URL должен включать протокол (http:// или https://)
- Активность ожидает полной загрузки страницы

### Back

**Описание:** Возвращается на предыдущую страницу в истории браузера.

**Входные параметры:**
- **Page** (обязательный) — страница браузера

### Forward

**Описание:** Переходит на следующую страницу в истории браузера.

**Входные параметры:**
- **Page** (обязательный) — страница браузера

### RefreshPage

**Описание:** Обновляет текущую страницу.

**Входные параметры:**
- **Page** (обязательный) — страница браузера

**Советы:**
- Используется для обновления динамического контента
- Полезно после действий, которые изменяют состояние страницы

## Управление вкладками

### CreateTab

**Описание:** Создает новую вкладку в браузере.

**Входные параметры:**
- **Browser** (обязательный) — объект браузера
- **Url** (необязательный) — URL для открытия в новой вкладке

**Выходные параметры:**
- **Page** — новая созданная страница

**Советы:**
- Если URL не указан, создается пустая вкладка
- Новая вкладка автоматически становится активной

### SwitchTab

**Описание:** Переключается на существующую вкладку по индексу или заголовку.

**Входные параметры:**
- **Browser** (обязательный) — объект браузера
- **Index** (необязательный) — индекс вкладки (начинается с 0)
- **Title** (необязательный) — заголовок вкладки (полное совпадение или частичное)

**Выходные параметры:**
- **Page** — страница выбранной вкладки

**Советы:**
- Укажите либо Index, либо Title (не оба одновременно)
- При поиске по Title сначала ищется точное совпадение, затем частичное
- Активность повторяет попытки до появления нужной вкладки (полезно для всплывающих окон)

### GetAllTabs

**Описание:** Получает массив всех открытых вкладок браузера.

**Входные параметры:**
- **Browser** (обязательный) — объект браузера

**Выходные параметры:**
- **Pages** — массив всех страниц браузера

**Советы:**
- Используйте для итерации по всем открытым вкладкам
- Полезно для обработки множественных результатов поиска

## Работа с элементами

### AwaitWebElement

**Описание:** Ожидает появления элемента на странице и возвращает его.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента

**Выходные параметры:**
- **Element** — найденный элемент
- **IsElementExist** — флаг существования элемента (true/false)

**Советы:**
- Используйте для динамически загружаемых элементов
- Активность выполняет повторные попытки поиска до успеха или таймаута
- Необходимо указать хотя бы один селектор (CSS или XPath)

### CheckWebElementExists

**Описание:** Проверяет существование элемента без ожидания (одна быстрая проверка).

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента

**Выходные параметры:**
- **IsElementExist** (обязательный) — флаг существования элемента (true/false)

**Советы:**
- Используйте для условной логики (IF-ветвления)
- Не выполняет повторные попытки, возвращает результат немедленно
- Более быстрая альтернатива AwaitWebElement для проверки наличия элемента

### FindWebElements

**Описание:** Находит все элементы, соответствующие селектору.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элементов
- **XPathSelector** (необязательный) — XPath-селектор элементов

**Выходные параметры:**
- **Elements** — массив найденных элементов

**Советы:**
- Используйте для работы со списками элементов (таблицы, меню, карточки товаров)
- Результат может быть пустым массивом, если элементы не найдены
- Полезно в циклах For Each для обработки множественных элементов

## Взаимодействие с элементами

### ClickWebElement

**Описание:** Выполняет клик по элементу на странице.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента

**Советы:**
- Активность ожидает появления элемента перед кликом
- Можно кликать по кнопкам, ссылкам, чекбоксам и другим интерактивным элементам
- Выполняет повторные попытки при неудаче

### InputText

**Описание:** Вводит текст в поле ввода (input, textarea).

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента
- **Text** (обязательный) — текст для ввода

**Советы:**
- Автоматически очищает существующее значение перед вводом
- Имитирует реальный ввод пользователя (посимвольно)
- Триггерит события input и change для корректной работы с JavaScript

### SelectOption

**Описание:** Выбирает опцию в выпадающем списке (select).

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента select
- **XPathSelector** (необязательный) — XPath-селектор элемента select
- **Value** (обязательный) — значение опции для выбора (значение атрибута value)

**Советы:**
- Value должен соответствовать атрибуту value элемента option, а не видимому тексту
- Триггерит событие change для совместимости с JavaScript обработчиками

### ScrollPage

**Описание:** Прокручивает страницу к элементу или на указанное расстояние.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента для прокрутки к нему
- **DeltaX** (необязательный) — смещение по горизонтали в пикселях
- **DeltaY** (необязательный) — смещение по вертикали в пикселях

**Советы:**
- Если указан CSSSelector, прокрутка выполняется к элементу (DeltaX и DeltaY игнорируются)
- Если селектор не указан, используются DeltaX и DeltaY для относительной прокрутки
- Полезно для загрузки ленивого контента (lazy loading)

## Получение данных

### GetTextFromWebElement

**Описание:** Извлекает текстовое содержимое элемента.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента

**Выходные параметры:**
- **Text** (обязательный) — текстовое содержимое элемента

**Советы:**
- Возвращает весь текст внутри элемента, включая вложенные элементы
- Использует свойство textContent (включает невидимый текст)
- Выполняет повторные попытки до успешного получения текста

### GetWebElementAttribute

**Описание:** Получает значение атрибута элемента.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента
- **AttributeName** (обязательный) — имя атрибута (например, "href", "src", "class", "id")

**Выходные параметры:**
- **AttributeValue** (обязательный) — значение атрибута

**Советы:**
- Полезно для извлечения ссылок (href), изображений (src), классов и других атрибутов
- Возвращает null, если атрибут не существует
- Типичные атрибуты: href, src, alt, title, class, id, value, data-*

### GetWebElementPosition

**Описание:** Получает координаты и размеры элемента на странице.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **CSSSelector** (необязательный) — CSS-селектор элемента
- **XPathSelector** (необязательный) — XPath-селектор элемента

**Выходные параметры:**
- **X** — координата X верхнего левого угла (в пикселях)
- **Y** — координата Y верхнего левого угла (в пикселях)
- **Width** — ширина элемента (в пикселях)
- **Height** — высота элемента (в пикселях)

**Советы:**
- Координаты относительно начала страницы, а не видимой области
- Полезно для визуальной верификации или создания скриншотов

## Дополнительные возможности

### InvokeJS

**Описание:** Выполняет произвольный JavaScript код на странице.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **Script** (обязательный) — JavaScript код для выполнения

**Выходные параметры:**
- **Result** — результат выполнения скрипта в виде строки

**Советы:**
- Мощный инструмент для сложных операций, недоступных через стандартные активности
- Результат автоматически преобразуется в строку (JSON для объектов)
- Примеры использования: получение localStorage, изменение стилей, вызов функций страницы
- Выполняет повторные попытки при ошибках

### DownloadFile

**Описание:** Скачивает файл с веб-страницы.

**Входные параметры:**
- **Page** (обязательный) — страница браузера
- **Url** (необязательный) — прямой URL файла для скачивания
- **CSSSelector** (необязательный) — CSS-селектор элемента ссылки для скачивания
- **XPathSelector** (необязательный) — XPath-селектор элемента ссылки для скачивания
- **SavePath** (необязательный) — путь для сохранения файла (директория или полный путь к файлу)

**Выходные параметры:**
- **SavedFilePath** — полный путь к сохраненному файлу
- **Data** — байты скачанного файла
- **IsSuccess** — флаг успешного скачивания (true/false)

**Советы:**
- Укажите либо Url напрямую, либо селектор элемента со ссылкой (атрибут href)
- Если SavePath — директория, файл сохраняется с автоматически определенным именем
- Если SavePath — полный путь, файл сохраняется точно по указанному пути
- Если SavePath не указан, файл сохраняется во временную папку системы
- Автоматически определяет имя файла из заголовков Content-Disposition или URL

## Лучшие практики

### Работа с селекторами

**Приоритет CSS над XPath:**
- Используйте CSS-селекторы, когда возможно — они быстрее и проще
- XPath полезен для сложных условий и навигации по структуре документа
- Если указаны оба селектора, выполнится CSS-селектор

**Создание надежных селекторов:**
- Предпочитайте селекторы по ID: `#user-name`
- Используйте уникальные атрибуты: `[data-testid="submit-button"]`
- Избегайте зависимости от структуры: `.container > div > span` (хрупко)
- Комбинируйте атрибуты для уникальности: `input[type="email"][name="username"]`

### Управление ожиданием

**Используйте правильные активности:**
- **AwaitWebElement** — для динамических элементов (Ajax, SPA)
- **CheckWebElementExists** — для быстрых проверок условий
- Не используйте фиксированные задержки (Delay), полагайтесь на ожидание элементов

**Настройка таймаутов:**
- Устанавливайте адекватные таймауты для медленных страниц
- Для быстрых операций уменьшайте таймауты

### Обработка ошибок

**Используйте Try-Catch:**
- Оборачивайте критичные операции в Try-Catch блоки
- Всегда закрывайте браузер в блоке Finally
- Логируйте ошибки для отладки

**Проверка существования:**
- Проверяйте существование элементов перед взаимодействием (CheckWebElementExists)
- Используйте условную логику для обработки разных сценариев

### Производительность

**Минимизация операций:**
- Объединяйте множественные операции через InvokeJS
- Используйте FindWebElements вместо множественных FindElement в циклах
- Переиспользуйте объекты Page и Browser

**Headless режим:**
- Используйте Headless=true для продакшн-сценариев (быстрее и меньше ресурсов)
- Используйте Headless=false только для отладки и разработки

### Работа с профилями

**UserDataDir:**
- Используйте для сохранения авторизации между запусками
- Создавайте отдельные профили для разных сценариев
- Периодически очищайте старые профили

### Стабильность

**Прокрутка к элементам:**
- Используйте ScrollPage перед кликом на элементы вне видимой области
- Это предотвращает ошибки "element not interactable"

**Ожидание загрузки:**
- После навигации (GoToUrl) используйте AwaitWebElement для ключевых элементов
- Это гарантирует полную загрузку страницы перед действиями

**Работа с вкладками:**
- Всегда получайте актуальный объект Page после SwitchTab
- Не переиспользуйте старые объекты Page из закрытых вкладок

### Безопасность

**Данные профиля:**
- Не храните чувствительные данные в общих UserDataDir
- Используйте отдельные профили для разных учетных записей

**Скачивание файлов:**
- Всегда проверяйте IsSuccess перед использованием скачанного файла
- Валидируйте содержимое и тип файла после скачивания

### Отладка

**Визуальный контроль:**
- Запускайте с Headless=false при разработке
- Используйте ScrollPage для визуализации обрабатываемых элементов

**Логирование:**
- Логируйте ключевые операции и полученные данные
- Сохраняйте скриншоты при ошибках (через InvokeJS)

### Масштабирование

**Параллельное выполнение:**
- Запускайте множественные экземпляры браузера для параллельной обработки
- Используйте разные UserDataDir для каждого экземпляра
- Ограничивайте количество одновременных браузеров для контроля ресурсов

**Повторное использование:**
- Переиспользуйте один браузер для множественных задач вместо перезапуска
- Создавайте новые вкладки (CreateTab) вместо новых браузеров

## Типичные сценарии использования

### Авторизация на сайте
1. StartBrowser с UserDataDir для сохранения сессии
2. GoToUrl на страницу входа
3. AwaitWebElement для полей ввода
4. InputText для логина и пароля
5. ClickWebElement на кнопку входа
6. AwaitWebElement для элемента успешной авторизации

### Сбор данных с таблицы
1. GoToUrl на страницу с таблицей
2. AwaitWebElement для таблицы
3. FindWebElements для получения всех строк
4. For Each по строкам с извлечением данных через GetTextFromWebElement

### Заполнение формы
1. GoToUrl на страницу формы
2. AwaitWebElement для формы
3. ScrollPage к полям при необходимости
4. InputText для текстовых полей
5. SelectOption для выпадающих списков
6. ClickWebElement для чекбоксов
7. ClickWebElement на кнопку отправки

### Скачивание файлов
1. GoToUrl на страницу со списком файлов
2. FindWebElements для всех ссылок на файлы
3. For Each по ссылкам с использованием DownloadFile

### Работа с динамическим контентом (SPA)
1. StartBrowser
2. GoToUrl на SPA
3. AwaitWebElement для начальной загрузки
4. ClickWebElement для триггера Ajax
5. AwaitWebElement для нового контента
6. GetTextFromWebElement для извлечения данных

---

**Примечание:** Эта документация описывает доступные активности для работы через визуальный конструктор. Все параметры настраиваются через интерфейс без необходимости написания кода.
